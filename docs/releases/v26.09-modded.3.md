# 26.09-modded.3 — First consolidated modded release

This is **edition 1 of the consolidated OpenLoco Modded feature set**. The `26.09-modded.3` version and `v26.09-modded.3` tag preserve build continuity. It supersedes modded.1 and modded.2; those GitHub releases and tags are retired at the owner's request, while their commits remain in history.

CargoDist is included on `master`, together with the accepted shared-line, timetable, signal and visual-order deliveries. Chris Sawyer's Locomotion is required; its original assets are not bundled.

## Changes from Locomotion and upstream OpenLoco

This independent fork builds on [OpenLoco](https://github.com/OpenLoco/OpenLoco), specifically its [26.09 baseline `e71abfb3`](https://github.com/OpenLoco/OpenLoco/commit/e71abfb3). Upstream supplies the open-source engine and its existing improvements. The following are this fork's additions over that baseline; this release does not claim every subsequent upstream change.

| Feature | Original Locomotion / OpenLoco baseline | Modded edition 1 |
| --- | --- | --- |
| Distribution | Classic cargo quantities/loading | Passenger/mail/freight destinations and automatic transfers across all vehicle modes |
| Orders | Individual vehicle lists | Optional shared lines plus compact visual block programming |
| Dispatch | Ordinary routes | Timetables, lateness and automatic spacing |
| Signals | Block signals | Additional path, chain and combined signals with physical occupation/reservation protection |
| Route UI | Native lists/number circles | Inline block editor, drag/drop, program progress, next-order arrow and conditional Path/All line display |
| Options | Native/OpenLoco gameplay options | Additional no-obsolescence, infinite-money and calendar-speed controls |

## Automatic cargo, passenger and mail transfers

- Create normal private routes or shared lines. A truck can feed coal from a mine to a combined road/rail station, then a train takes it to a power plant. No Transfer/Unload order is required.
- An ordinary station with no nearby industry can hold cargo between feeder and onward services, including several final consumers. It needs a compatible onward service to an accepting destination; there is no special warehouse building or mode.
- Passengers/mail can travel from town bus/tram stops to an outer train station, across rail/ship/air services, then by another feeder to their final stop. Return journeys, distinct stops in one town and several destinations sharing one station/compartment are supported.
- Combined facilities with one station ID share waiting cargo. Separately named nearby stations require a connecting service. Waypoints and route-through orders never transfer cargo.
- Useful through cargo stays aboard. Intermediate acceptance delivers only groups addressed to that station. Partial loads, repeated stops, cargo restrictions, full-load orders and possible logic branches participate without forcing rule choices.
- Routing favours useful forward journeys, considers capacity and publishes completed plans incrementally. Pending or unavailable routes are shown in compact, expandable native Cargo-tab summaries.
- Automatic is the default for new games and older saves: symmetric passengers/mail, asymmetric freight. Choose **Options → Miscellaneous → Cargo transfers → Classic** for native distribution. Explicit saved/mixed choices are preserved.
- Feeder profit receives virtual credit. Final delivery pays company cash once through the native origin/distance/age formula and deducts earlier credit from the final carrier's reported revenue. Shared-line earnings aggregate vehicle results; delays can reduce final reported profit.

## Lines, timetables, signals and block orders

- Shared lines support trains, road vehicles/trams, ships and aircraft, with assignment, detachment, cloning, colours and route views alongside ordinary private orders.
- Timetable targets, late/on-time information and automatic spacing share the native route system. Platform preferences do not force pathfinder platform selection.
- Path/chain/combined signals retain native block signals and protect occupied track, wagons and other vehicles' reservations. Directional waypoints retain their required route; a blocked required continuation waits instead of taking an unrelated free loop. Native rail and road/tram placement bounds fixes are included.
- Click **Rules** in Vehicle Route or shared-line Orders to expand that window. Native fonts, bevels, plain stop/waypoint rows and white number circles remain. There is no separate Rules-window workflow.
- Blocks include **If, Else if, Else, And/Or, Repeat (1–20), Forever, Break, Wait until, Skip, Go to and Group**. Sections can span several stops, waypoints and cargo instructions. Fields are clickable; blocks, selected orders and whole sections support validated drag/drop, resizing and pointer previews.
- Checks cover station/vehicle cargo, destinations, full/empty/space, actual rail-platform occupation, timetable status and year. Green/red condition feedback, program progress and the white next-order arrow remain visible.
- Shared programs keep independent per-vehicle waits/counters. Waits use native physical arrival/braking; station loading continues. Execution is bounded per tick and never bypasses movement or reservations.
- Existing Path/All overlays follow live logical choices. Standalone CargoDist windows and congestion overlays are superseded by compact native Cargo views.

## Download and setup

Download **`OpenLoco-v26.09-modded.3-windows-x64.zip`** and its **`.sha256`** asset. Extract to a separate folder and run `OpenLoco.exe`. Select an existing original Locomotion installation, or launch with `--locomotion_path "C:\Path\To\Locomotion"`. Original assets can be obtained with [Locomotion on Steam](https://store.steampowered.com/app/356430/) or [GOG](https://www.gog.com/game/chris_sawyers_locomotion).

The ZIP contains the Windows x64 Release executable, project languages, the CMake-fetched OpenGraphics objects and project notices. Original DAT/G1/music assets, player saves, profiles and test executables are excluded. Other platforms require source builds; this release publishes no verified Linux/macOS binaries.

## Saves and boundaries

SV5/SC5 packed layouts remain unchanged. Keep each save with its matching **`.olines` v5**, **`.osignals` v3**, **`.orules` v1** (including optional PHASES data) and **`.ocargodist` v1** companions. CargoDist preserves settings, destinations, accounting and resumable routing. Missing companions migrate native quantities; rejected data produces a named warning and reconstructs amounts without inventing transfer credit. Keep backups before moving saves between builds; native-only loads cannot restore all modded state.

Routing uses compatible placed services/order connectivity and possible branches, rather than forecasting the exact future physical journey or condition outcome. A missing service, incompatible cargo or blocked connection can leave cargo waiting. Multiplayer, raised world/object limits, NSF/NOF, consists/coupling/shunting and a text language/mod loader remain outside this release.
