# 26.09-modded.2

Historical release notes. **Retired by D69 in favour of [26.09-modded.3](v26.09-modded.3.md), the first consolidated modded edition including CargoDist.** The old GitHub release/tag is removed at the owner's request; commits and this audit record remain.

Programmable block orders now run on private vehicles and shared lines, with native inline editing in their order windows. Chris Sawyer's Locomotion is still required to play.

- Add If, Else if, Else, And/Or, Repeat/Forever, Break, Wait until, Skip, Go to and named Group blocks. Groups can span several stops, waypoints and cargo instructions.
- Check station cargo, vehicle fullness/space, physical rail-platform occupation, timetable status and the year. Shared-line vehicles keep independent counters and waits.
- Edit directly in Vehicle Route or shared-line Orders. Rules expands that window with a scrolling palette, Actions/Details/bin, multi-row dragging/resizing and guarded native field dialogs. Stops and waypoints retain the base-game captions and white number circles.
- Show current program progress and the next destination together, with green/red branch feedback and the white route arrow. Shared-line Path/All previews omit inactive sections and retain completed geometry during refreshes.
- Keep waits at reached stops/waypoints with native approach/braking and station cargo handling. Rule state resumes through the companion save file.
- Fix required-waypoint routing and Path/Chain/combined signal protection, including occupied or reserved continuation beyond a waypoint and complete curve/wagon occupation. Fix asymmetric rail placement/reversal bounds checks.
- Keep existing shared lines, timetables, colour Schemes/Own settings and gameplay options. No mod loader or text scripting language is added.

## Download and saves

The attached Windows x64 ZIP contains the Release executable, project language files, the existing OpenGraphics object pack and project notices. Original Locomotion graphics, music and player saves are not included. Extract to a separate folder and use your existing Locomotion installation.

Packed SV5/SC5 remains unchanged. Shared lines/signals retain `.olines` v5 and `.osignals` v3; programmable rules use `<save>.SV5.orules` v1 with the optional PHASES extension. Keep matching companions together. Keep a separate save and matching companions when testing rollback to modded.1: the older build does not support programmable-rule state.

The previous `v26.09-modded.1` release/tag remains available as the rollback checkpoint. The merged Phase 4 implementation was accepted by the user; earlier individual gameplay checks not explicitly reported remain recorded separately in development status.
